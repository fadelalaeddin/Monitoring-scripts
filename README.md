# Linux Automation Scripts 

A collection of monitoring scripts for system administration and automation 

## Scripts Included:

### 1. Disk Space Monitoring
**Script:** `disk-space-monitor.sh`

Monitors root disk usage and checks it against a defined threshold.

### 2. Log File Cleanup
**Script:** `log-file-cleanup.sh`

Removes old `.log` files to help free up disk space.

### 3. Service Health Check
**Script:** `service-health-monitor.sh`

Checks whether a Linux service is running and starts it if necessary.

### 4. Automated Backup
**Script:** `backup.sh`

Creates a compressed backup of a specified directory.

### 5. User Management
**Script:** `create-user.sh`

Creates a Linux user and adds the user to the `sudo` group.
